Comment activer la connexion ?

1. Hébergez cette page sur une adresse HTTPS (ou utilisez localhost pour un test). 2. Dans Google Cloud Console, activez Google Calendar API et Google Tasks API. 3. Créez un identifiant OAuth 2.0 de type « Application Web » et ajoutez l'origine exacte du site dans les origines JavaScript autorisées. 4. Collez l'identifiant client ici, connectez-vous et activez la synchronisation.

Mes données

Vos activités sont enregistrées dans ce navigateur. Google ne reçoit que les éléments que vous classez comme « Tâche » ou « Agenda », après autorisation.

À savoir : les données locales de 3 × 8 ne sont pas encore synchronisées entre appareils. Exportez régulièrement vos données. L'export .ics est indépendant de la liaison Google.

Le principe

Ce planning est un repère, pas un examen. Un moment laissé libre peut être une très bonne décision.

Le sommeil prévu est de 6 h. Vous pourrez faire évoluer cette grille si vous décidez d'allonger vos nuits.

3 × 8 • Un cadre pour vivre, pas une course à remplir les heures.
